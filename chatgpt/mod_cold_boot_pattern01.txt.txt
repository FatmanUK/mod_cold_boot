# mod_cold_boot_pattern01.txt

## Pattern 01: Main Thump A

This is the core groove for **Cold Boot**. It is deliberately repetitive and mechanical, with a descending pad line and two restrained stab accents.

Keep the existing settings:

```text
Speed:    6
BPM:      145
Channels: 4
Rows:     64
```

The channel roles are:

```text
Ch1: kick and snare
Ch2: PopBass
Ch3: KorgString
Ch4: closed hat and occasional stab
```

Because `PopBass` and `KorgString` are looped, an empty cell does **not** stop them. The currently playing sample continues until another note replaces it. That sustained behaviour is intentional.

Everything not shown below should remain completely empty.

The implied four-bar harmonic movement is:

```text
Bar 1: C minor centre
Bar 2: C minor with E-flat and F movement
Bar 3: A-flat tension
Bar 4: F to G turnaround
```

You should hear:

```text
Ch1: a slow, heavy kick/snare machine pulse
Ch2: short bass notes defining the harmonic movement
Ch3: C -> A# -> G# -> F descending pad line
Ch4: offbeat hats, with stabs on rows 30 and 62
```

Pattern 01 should feel noticeably more active than Pattern 00, but not yet crowded. The two stabs are markers rather than lead notes, and row 62 should lean naturally into Pattern 02.

# mod_cold_boot_pattern02.txt

## Pattern 02: Main Thump B

This variation keeps the machinery of Pattern 01 running, but makes it more uneasy:

* The kick gains syncopated double hits.
* The bass movement becomes less predictable.
* The pad passes briefly through `C#4`, creating a cold chromatic scrape.
* A descending diagnostic bell sequence appears once per 16-row section: `D#5 → D-5 → C#5 → C-5`.

Pattern 02 is used twice in the order list, once before Pattern 01 and later before Pattern 05. Its ending is deliberately neutral enough to connect cleanly to either destination.

`C20` is a standard ProTracker **set-volume** effect:

```text
C20 = set the channel volume to hexadecimal 20
    = decimal 32
```

It keeps the diagnostic bells behind the groove rather than letting `ExBells` leap out like a doorbell in a server bunker.

The four harmonic sections are:

```text
Rows 00–15: C minor centre
Rows 16–31: chromatic C-sharp pad tension
Rows 32–47: B-flat suspended region
Rows 48–63: G tension resolving toward C
```

The intended result is recognisably related to Pattern 01, but less settled. Pattern 01 says, “the machine is operating.” Pattern 02 quietly adds, “the machine may have its own agenda.”
